DYNASTY 8 V13 — Connexion à Supabase (optionnelle)

1. Créer un projet sur https://supabase.com
2. Ouvrir SQL Editor et exécuter supabase-setup.sql.
3. Dans Authentication > Users, créer ton utilisateur administrateur.
4. Copier son User UID et exécuter dans SQL Editor :
   insert into public.admin_users(user_id) values ('TON-UUID-ADMIN');
5. Dans Project Settings > API (ou Connect), copier l'URL du projet et la clé publique anon/publishable.
6. Les coller entre guillemets dans supabase-config.js. NE JAMAIS y mettre service_role / secret key.
7. Déployer le dossier dynasty8_site sur Netlify (Deploys).
8. Aller sur admin-annonces.html, se connecter et ajouter une annonce.
9. Vérifier biens.html dans un autre navigateur : les annonces sont désormais partagées.

ATTENTION :
- Tant que supabase-config.js est vide, le site reste en mode local V12.
- L'éditeur des zones (admin.html) reste LOCAL, non connecté à Supabase.
- Il n'y a pas de carte GTA V officielle dans cette archive, la carte est encore schématique.
- Les anciennes annonces locales ne sont pas transférées automatiquement. Les recréer en ligne.
- Ne partage pas ton mot de passe ni de clé secrète.
